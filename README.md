# 灵活就业社保优化顾问（flexi-social-optimizer）

> 自由职业者、个体户、平台从业者的社保决策工具。输入你的年龄、城市、收入，自动算出医保该不该交、养老金划不划算、标普 500 定投能替代多少——最后给你一份「今天就该做」的执行清单。

## 这是什么？

一个 WorkBuddy Skill，基于深度研究报告《中国灵活就业者养老策略优化研究》。核心逻辑：

1. **医保必须交** — 不是因为"国家兜底"，而是因为没医保买商业险贵 2-3 倍
2. **灵活就业职工养老看寿命** — 活到 70 岁前 IRR 不到 3%，活到 80 岁才 6%
3. **居民养老是被忽视的中间选项** — 年缴 300-10,000 元，100% 进个人账户、可继承
4. **标普 500 定投负责上限** — 近百年年化 10%，月投 1,000 元 33 年后约 290 万

## 安装

WorkBuddy 的 Skill 放在用户级目录 `~/.workbuddy/skills/`，一条命令即可装好：

```bash
git clone https://github.com/qishuai6/flexi-social-optimizer.git ~/.workbuddy/skills/flexi-social-optimizer
```

装完重启（或刷新）WorkBuddy 对话，就能用 `/社保优化`、`/灵活就业`、`/自由职业养老` 等触发词唤起。

> 也可把目录换成项目级路径 `{你的工作区}/.workbuddy/skills/`，仅对当前项目生效。

## 功能

| 功能 | 说明 | 触发示例 |
|------|------|---------|
| 🏥 医保必要性 | 分析有/无社保身份的成本差 | "只交医保不交养老行吗？" |
| 📊 职工养老 IRR | 按年龄/性别计算内部回报率曲线 | "职工养老交 20 年划算吗？" |
| 🏘️ 居民养老待遇 | 按省份计算各档次领取金额 | "居民养老选哪个档次？" |
| 📈 标普 500 测算 | 从当前到退休的定投终值 | "每月 1000 能变成多少？" |
| ⚖️ 三方案对比 | 激进/稳健/保守方案全对比 | "/社保优化" |

## 触发方式

## 工作流程

```
用户输入个人信息
    ↓
  收集画像（年龄/性别/城市/收入/风险偏好）
    ↓
  ┌─ 医保必要性分析 ──→ 月缴费 + 无医保隐性成本
  ├─ 职工养老 IRR ──→ 不同寿命的回报率曲线
  ├─ 居民养老待遇 ──→ 低/中/高三档月领取金额
  └─ 标普 500 定投 ──→ 保守/基准/乐观三情景终值
    ↓
  三方案对比表（激进/稳健/保守）
    ↓
  推荐方案 + 本月执行清单
```
